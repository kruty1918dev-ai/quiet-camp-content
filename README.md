# QuietCamp content

Публічні пакети рівнів для QuietCamp Android.

Перші 10 рівнів містяться у застосунку. Пакети для решти кампанії та
історичних збережень застосунок завантажує з GitHub Releases і перевіряє
за SHA-256. Повна базова кампанія має 100 рівнів.

[Пакети контенту](https://github.com/kruty1918dev-ai/quiet-camp-content/releases/tag/content-0.1.4-96924a450c83)
— 18 архівів, разом близько 190.6 MiB. Сховище підключено до клієнта
0.1.5; підписані локальні APK-кандидати вже зібрано. Перевірка запуску та
gameplay триває; публікація контенту не означає приймання гри.

У цьому репозиторії публікуються готові ігрові пакети та контрольні суми.
